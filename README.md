# Quran Shorts Bot

ئەم بۆتە لە GitHub Actions کار دەکات و کۆمپیوتەری خاوەن کەناڵ پێویست ناکات کراوە بێت. ڤیدیۆی ستوونی 1080×1920 دروست دەکات و سێ جار ڕۆژانە، لە 11:00 و 16:00 و 20:00 بە کاتی بەغدا، بە شێوەی public لە YouTube بڵاوی دەکاتەوە.

## ناوەڕۆک و ڕیزبەندی

- تەنها قارییە allowlist کراوەکان بەکاردێن؛ هاني الرفاعي دوای global Content ID block لابراوە.
- هەر پۆستێک قاری و ئایەتێکی جیاواز هەڵدەبژێرێت؛ لە یەک سوورەتدا بۆ هەموو قارییەکان ناوەستێت.
- هەموو 6,236 ئایەتی قورئان لە ڕیزبەندییەکەدان. لەگەڵ 5 وەشانی allowlist کراوی تلاوەت نزیکەی 31,180 تێکەڵە هەیە، پێش لابردنی ئایەتە درێژەکان.
- قەبارەی دەنگ دوای دابەزاندن بە FFmpeg پێوانە دەکرێت. ئایەت هەرگیز نابڕدرێت؛ ئەگەر زیاتر لە 58 چرکە بێت، ئەو تێکەڵەیە پەڕێندرێت.
- لە دوای تەواوبوونی ئایەت 1 چرکە بێدەنگی زیاد دەکرێت بۆ کۆتاییەکی پاک.
- ناوی سوورەت، ژمارەی ئایەت و ناوی قاری لەسەر کارتەکە و لە ناونیشاندا دەنووسرێن.
- دەقی عوسمانیی پشکنراوی هەر ئایەت لە Quran Foundation وەردەگیرێت؛ دەقی درێژ یان نادیار پەڕێندرێت.
- پێنج دیمەنی original بە ڕیز دەگۆڕێن: دارستان و باران، شاخ و تەم، شەوی ئەستێرەدار، دەریا و مانگ، و مزگەوتی سپێدە.
- quality gate دوو فریمی جیاواز پێوانە دەکات؛ ئەگەر جووڵە بەڕوونی نەبێت، ڤیدیۆکە upload ناکرێت.
- ناونیشان، وەسف و tag ـەکانی YouTube تەنها بە عەرەبی و ئینگلیزی دروست دەکرێن.
- دوای upload یەکێک لە 8 CTA ـی جیاواز بە عەرەبی و ئینگلیزی وەک comment دەنێردرێت؛ شکستی comment ڤیدیۆکە تێک نادات.
- upload ـە تۆمارکراوەکان بۆ rejection و region restriction پشکنین دەکرێن؛ قاریی ناوەڕۆکی بلۆککراو خۆکارانە لە allowlist لادەبرێت و دەخرێتە blocklist.

دەنگ لە Quran Foundation (Quran.com) وەردەگیرێت و لە وەسفی هەر ڤیدیۆیەک سەرچاوە و [مەرجەکانی بەکارهێنان](https://api-docs.quran.com/legal/developer-terms/) دانراون. خێرایی و تۆنی دەنگ ناگۆڕدرێن.

## پاراستن لە دووبارەبوونەوە و وەستان

تۆماری پۆستەکان لە `.bot-state/published.json` دەپارێزرێت. هەر کارێک پێش upload تۆمار دەکرێت و دوای سەرکەوتن ناسنامەی ڤیدیۆکە زیاد دەکرێت. ئەمە ڕێگری لە upload ـی دووبارە دەکات، تەنانەت ئەگەر GitHub Actions لە ناوەڕاستدا بوەستێت. ڕیزبەندی لە `cursor` ـەوە بەردەوام دەبێت و بە کۆتایی لیست دەگەڕێتەوە سەرەتا.

ئەگەر API، quota، OAuth یان ئینتەرنێت کاتییەن کێشەیان هەبێت، GitHub ئەنجامی کارەکە نیشان دەدات و schedule ـی دواتر هەر بەردەوامە. ئەگەر دۆخی upload نادیار بێت، بۆ پاراستن لە دووبارەبوونەوە بۆتەکە دەوەستێت تا تۆمارەکە پشکنرێت.

## ڕێکخستن

- `automation.json`: چالاک/ناچالاک، ناسنامەی کەناڵ و public/private.
- `catalog.json`: سەرچاوە، allowlist و blocklist ـی قارییەکان، سنووری 58 چرکە و 1 چرکە کۆتایی.
- `.github/workflows/quran-shorts.yml`: schedule و جێبەجێکردن.
- `cloud_runner.py`: هەڵبژاردن، دروستکردن، پشکنین و upload.

## داشبۆردی بەڕێوەبردن

داشبۆردێکی responsive لە `dashboard/` هەیە کە لە مۆبایل و لاپتۆپ کار دەکات.
`dashboard_server.py` داتا لە remote ledger ـەوە دەخوێنێتەوە و کردارەکان بە شێوەی
پارێزراو workflow ـی هەمان GitHub بەڕێوە دەبات؛ هیچ GitHub یان YouTube token ـێک
بۆ browser نانێردرێت.

بۆ دەستپێکردن بە شێوەی local:

```powershell
$env:GITHUB_TOKEN = "token-with-actions-write-and-contents-read"
$env:DASHBOARD_KEY = "a-long-random-key"
python dashboard_server.py
```

پاشان `http://127.0.0.1:8787` بکەرەوە. داشبۆردەکە preview، پۆستکردنی
دەستی، schedule catch-up، ledger، health و کۆتا پۆستەکان نیشان دەدات. ژمارەی
پۆستی دەستی تا 5 ـە و هەر dispatch ـێک بە concurrency و remote ledger ـی
ئێستا پارێزراوە. بەشی TikTok وەک integration ـێکی جیاواز ئامادەکراوە و تا
OAuth و Content Posting API ـی TikTok ڕێک نەخرێت، هیچ upload ـێکی نادیار ناکات.

## پشکنین

```text
python -m unittest discover -s tests -v
```

36 تاقیکردنەوە ڕیزبەندی، تەواوی ئایەت، metadata، tag، CTA، claim auto-block، دەقی پشکنراو، گۆڕینی دیمەن، پێوانەکردنی ماوە، پەڕاندنی ئایەتی درێژ، دروستکردنی ڤیدیۆ و پاراستنی upload دەپشکنن. پێشبینینی GitHub Actions ـیش پێش چالاککردنەوە لە Linux دروست دەکرێت.
