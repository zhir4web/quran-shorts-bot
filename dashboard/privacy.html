Privacy Policy

Last updated: October 2, 2026

This policy describes how Quran Bot, a private tool operated by the owner of the Quran Shorts channel, processes information when the owner connects YouTube or TikTok or uses the dashboard. The service is not affiliated with Google, YouTube, TikTok, or Quran Foundation.

Google and YouTube data

When the owner authorizes YouTube, the app receives OAuth access and refresh tokens and the permissions the owner grants. It uses those permissions to identify and confirm the selected channel; upload and publish videos at the owner's request or according to the owner's schedule; organize channel videos into playlists; add the configured comment to an uploaded video; and read video statistics and YouTube Analytics data for upload checks and performance reports. This can include channel and video identifiers, video metadata, playlist information, view, like and comment counts, watch time, average view duration, and related report values.

Google user data is used only to provide and maintain the YouTube channel-management features described above. It is not sold, used for advertising, or used to train generalized AI or machine-learning models. The app does not transfer Google user data to unrelated third parties. It is processed by the infrastructure providers needed to run the owner's requested workflows, as described below, and is handled in accordance with the Google API Services User Data Policy, including its Limited Use requirements.

Other information processed

  • Videos and Quran metadata: the selected recitation, licensed background assets, captions and upload metadata are combined to render videos and carry out the owner's request. YouTube receives videos and metadata that the owner chooses to upload; YouTube controls their publication, display and retention there.
  • Public workflow ledger: the public GitHub repository stores operational records such as video IDs, upload status and times, reciter and visual-theme labels, schedule history, and YouTube statistics or report summaries. Anyone who can access the public repository can read this ledger. OAuth tokens and dashboard keys are not intentionally written to it.
  • GitHub Actions: the YouTube OAuth token is stored as the repository's encrypted YOUTUBE_TOKEN Actions secret and is supplied to the workflow runner only while a workflow runs. GitHub processes workflow logs and security information under its own policies.
  • TikTok: if the owner connects TikTok, the service receives the account identifier, granted permissions, and access and refresh tokens. Tokens are encrypted before storage in Vercel Blob. When the owner requests a TikTok draft, the selected video is transferred to TikTok as an unpublished inbox draft for the owner to review and publish.
  • Dashboard and custom clips: the dashboard key is held in the browser tab's session storage and sent over HTTPS to authenticate requests. If the owner submits a custom video, it may be temporarily processed by Vercel Blob and GitHub Actions; the workflow attempts to remove the temporary source file after a successful YouTube upload.

Storage and service providers

The app relies on GitHub Actions to run video workflows and hold the encrypted YouTube token secret, GitHub to host source code and the public workflow ledger, Vercel to host the dashboard and temporarily process submitted clips, TikTok to receive requested drafts, and Google/YouTube to provide the authorized APIs and store uploaded videos. These providers may process operational and security logs under their own policies. OAuth tokens are kept separate from the public ledger.

Retention and choices

The YouTube token remains in the GitHub Actions secret while the connection is needed. The TikTok authorization is retained while that connection is in use. The public ledger is retained in the repository and its Git history. Uploaded videos and drafts are subject to YouTube's and TikTok's own storage and deletion controls. Temporary custom-video files are intended to be removed after a successful YouTube upload, although provider backups or logs may persist for limited periods under provider policies. The owner can revoke Google or TikTok access from the relevant account's security or app settings; future API access then stops, and the operator can remove the corresponding stored token.

Security and contact

The dashboard uses HTTPS and a dashboard key. OAuth credentials are stored outside the public source repository. No online service can guarantee absolute security. For a privacy question or to request removal of stored authorization data, contact the project maintainer through the Quran Shorts project page. Do not include passwords, access tokens, or private account details in a public issue.

This tool is intended for its channel owner. If it is made available to other users or changes how Google user data is used, this policy and the app's disclosures must be updated first.
